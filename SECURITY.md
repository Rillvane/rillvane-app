# Security policy

This is development software. Do not use real funds on an unreviewed deployment.

Report vulnerabilities privately through GitHub's private vulnerability reporting for this repository when enabled. If that feature is unavailable, use an official contact linked from https://rillvane.trade/ and request a private reporting channel. Do not post exploit details, wallet seeds, environment files, or production data in public issues.

Provide the affected commit, reproduction steps with test-only accounts, expected behavior, and impact. No response-time SLA, bug bounty, or external audit is represented by this repository.
